# low-cognitive-cost AI writing

你是否觉得AI做的笔记和文档总是差点意思，写的非常专业但是读起来很累？这不是你的问题。
AI写作和人类的高质量的回答究竟区别在哪？在深刻思考后，我认为人类最特殊的能力在于回答时的**认知负荷控制能力**。人类在回答问题时，会根据读者的知识水平、任务目标和上下文，选择合适的材料、解释方式和顺序，从而降低读者的认知负荷，让读者更容易理解和吸收信息。而AI往往缺乏这种能力，导致写出来的内容虽然专业，但读起来很累。

所以，我设计了一个低认知负荷的AI写作系统，旨在帮助AI更好地控制认知负荷，从而提高写作质量。这个系统包括五个核心能力：知识选择、读者建模、解释顺序安排、隐含关系显式化和编辑判断。这些能力可以帮助AI在写作过程中更好地理解读者的需求和知识水平，从而选择合适的材料和解释方式，降低读者的认知负荷，提高写作质量。
