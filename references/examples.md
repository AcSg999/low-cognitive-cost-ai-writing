# Examples · 写作案例与回归记录

## PPO vs SAC · 从一条观测走到两种训练决策

本次回归用三个实际文本。先读用户原稿，确认事实、切片、剪刀案例和关键引证，再用上一轮已有图和算例的改稿作较强对照。最后对新稿做同题走查、重算数值与渲染检查。阅读路径记录的是文稿里有哪些明确入口和必要步骤。样本没有招募读者，也没有测量真实阅读耗时或延迟记忆。

### 总控和模型先解决什么

核心问题是“策略变了以后，一条旧交互还能为学习提供什么，这怎样影响样本和时间成本”。以 Deep Dive 为主。在达标成本处借用 Reference 式对照表。目标读者已经熟悉学习和控制的基本概念。正文需要交代裁剪 PPO 的批次利用、SAC 的目标组成、覆盖如何影响估值、达标成本怎样计价。更完整的最大熵推导和算法选型不在当前切片。固定策略下收缩性保留到能判断它的适用边界。

从“同一次小幅夹紧”分两路。PPO 给它算一次批内优势，策略改变后要新轨迹直接观察新行为。SAC 保留实测转移，后续量依当前策略生成，在线 Q 回到原记录的状态动作。后者立即引出估值依据。成本对照接在两个机制之后，区分环境步数、更新次数和实际耗时。

### 实际迭代和可复算检查

- **第一轮发现因果问题**。上一版数字显示了重算机会，没有隔离“策略变动”。改用两个概率分布并固定记录、目标网和熵权重。两分布是同一对概率的排列，故平均熵贡献相等。数值重算通过。若任务终止，则在两种分布下都回到同一个实测奖励。
- **第二轮发现图义问题**。如果沿源图只能看到“以旧状态动作拟合”的末框，读者还得回头补出来源。把索引画成一条独立虚线。总图在第一次预览中可以被读成算法时间线，于是在稿件图下明确其箭头是解释路径，避免把覆盖节点当成必经训练步骤。
- **恢复路径走查**。用“重抽动作”和“任务终止”两问检查复习题。目标式后一段能答出两个条件，概率表支持继续回答换策略的平均效应。从总图的“实际耗时”走到达标成本小节，并验证了开头四条直达链接和复习题的返回链接。
- **保留的有效做法**。同一剪刀案例、PPO 裁剪的正优势例子、三步价值传播、墙钟成本数字以及权威出处均有对应段落。旧稿中未随仓库提供的本地手记链接，在新稿用可直接核对的论文入口承接。

### 换一种困难测试 · PID 微分冲击

给定值跳变时，为什么微分项会冲一下？目标是判断哪种微分输入会在第一个采样时点变大。用一个小表就能说明。定义给定值为 $r_k$，测量为 $y_k$，误差为 $e_k=r_k-y_k$，采样间隔为 $\Delta t$。假设给定值从 0 跳到 1，两个相邻采样中测量暂为 0。对误差差分得到 $1/\Delta t$，对测量取负差分得到 0。这个算例交代了差分的输入和时点，用不到完整 PID 推导。若测量也变化，后一项随测量变化。短 Concept 的标题、对照和条件足以恢复，不需要总图或复习题。
