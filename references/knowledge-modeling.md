# Knowledge Modeling · 建立共享的知识模型

## 目标与依据

从核心问题出发，找出支撑解释、预测或操作的最小关系网络。教学、图形和复习入口共用这份模型。概念图方法强调用一个焦点问题选择真正有意义的关系。本项目据此把知识模型围绕读者任务组织，并额外追踪时间、证据和实现角色。 [Cañas 与 Novak，概念图的焦点问题](https://cmc.ihmc.us/cmc2006Papers/cmc2006-p247.pdf)

它首先解决两种认知困难。零散事实太多时，读者无法判断哪些需要一起记。事实本身都正确却缺关系时，读者要自己拼出因果、变量来源或先后。知识模型应把这些关系变成可检查的陈述。

## 工作方法

1. 从读者最终要完成的判断倒推。把结论改写成可以解释、验证、预测或查到的动作。题目过宽时，问哪些子问题共用一条机制或同一条读者任务。共享机制的保留为分支，独立问题作为相邻切片。
2. 提取最少的对象和关键主张。对象可以是一个概念、变量、阶段、事实、假设或观测。给会影响结论的主张标出依据。区分任务假设、算法或实现定义、从条件推导出的结论、具体实验观察、需要进一步验证的推断。
3. 给关键关系写出动词与条件。把“actor、Q、回放相互联系”改成可复核的句子。例如“当前 actor 在记录中的下一状态采新动作”“两个目标 Q 评价该动作”“目标用于拟合旧状态动作对上的在线 Q”。如果环路里同一变量出现多次，写出时点和更新方式。
4. 试删一个块，并检查它对读者任务的影响。有助于理解结论或决定边界的块保留。仅需定位的知识挂到索引。切片外的材料可以链接到原来源。遇到反例可能使正文结论失效时，回到主张补一个条件。
5. 对图稿或难段反查关系。画图时遇到无法命名的边，先问角色或时点是否混用。讲解时需要额外条件才能推出结论，回到模型登记条件。复习入口找不到关键结论时，检查它是否在模型里有一个稳定的术语和位置。

| 关系 | 检查问题 | 常见错误 |
| --- | --- | --- |
| 概念依赖 | 读者要懂甲才能理解乙吗？ | 把同一领域所有主题连在一起 |
| 数据流 | 甲是乙计算的输入、指定位置的索引，还是产生后的输出？ | 把旧动作画成 SAC 下一动作的输入 |
| 时间或控制顺序 | 哪一步先发生，分支需要什么条件，下一次循环何时开始？ | 把同步更新和采样画成同一时点 |
| 因果或反馈 | 改变甲经由哪条机制影响乙？条件是什么？ | 从工作流连线直接推断因果 |
| 比较 | 两边比较的对象、单位、条件是否相同？ | 把梯度步数当成环境步数 |
| 证据或条件 | 该来源直接支持什么强度的主张？ | 把示意数字或一次实测当成普遍结论 |

### 视觉候选与建模输出

每次技术写作检查候选是否在当前切片内。阶段和状态能否沿时间追踪，数据经过哪些模块，架构中谁连接谁，公式各项从哪里来，哪些量组成反馈，哪些概念互相依赖，两种机制在哪条路径上不同，长文如何回到局部。单条路径也可能有价值。例如追踪一个动作从回放记录到估值再到更新对象，难点是角色与时点，而非分支的数量。

每个值得画的候选交给 [视觉知识工程](visual-reasoning.md)。给它一个读者能完成的判断、一组节点和带方向的关系、必要条件与建议插入位置。标明由图展示的关系和由正文解释的假设、推导或边界。若一行定义或一张同口径表就足以完成任务，记录这条理由即可。紧凑稿可以在写作时完成这项检查。

### 一跳前置的实际判法

从最小关系网络挑出正文直接使用、读者有必要回查的外部知识。比如 PPO 的优势估计和 SAC 的状态动作价值是直接接口。优势估计背后的概率论学习路线由优势估计笔记承接。索引只给名称、文中用处与可访问的入口。关键新符号和当前机制的角色说明仍要在正文首次使用前给出。读者对某个必要概念明显欠缺时，可以先用一句话定义这里需要的部分，或据此缩小切片。

## 使用条件与常见失败

单一事实或短说明只需快速确认对象与范围。解释多个机制、对照论文与实现、改写有错误或冲突的材料时，适合显式画出骨架并记录来源。Tutorial 的模型强调前置状态、动作、副作用和可观察结果。Reference 的模型强调检索键、参数、默认值、版本和边界。Deep Dive 需要能复述因果或推导链。

常见失败包括把原论文目录当成认知路径，把术语表当成关系图，只留下肯定结论而丢掉成立条件，或者为了完成前置列表递归追索教材。返工时先看哪个读者判断失败，再缩小到与它直接相关的关系。

## 输出与质量检查

给下游使用的结果可以是简短提纲、若干带动词的关系或可视骨架。长文至少能指出核心问题、边界、关键主张、关系、直接前置和正文位置。只在对照、审阅或用户需要时交付内部建模记录。检查是否能解释每条关键边、区分证据与推断、找出一条删去便会改变结论的假设。若别人用模型画图能画出两种相反的更新方向，先修模型。

## 技术写作实例 · 旧交互的三个角色

跟踪剪刀快滑落时的一次夹紧。PPO 使用本批轨迹上的优势和概率比更新策略。SAC 从回放读取实测转移，在下一状态重新采动作，使用算出的目标拟合原记录的状态动作对。接下来分出两条后果。持续可用的证据关系到交互次数，估计的后续价值关系到覆盖、误差向前传播和更新成本。最小模型应能解释这两条分支。
